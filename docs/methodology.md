# 收录方法与覆盖说明

## 时间与产品范围

目标窗口1996-10-13—2026-10-13。发生、生产、召回公告与报告发表时间分别记录；不把产品保质期当作发生日期。主体是粉状婴幼儿配方，扩展收录已注明身份的特殊营养用途、儿童配方、原料及假冒/误导销售案件。病例人数只记录来源的指定时点，不累加不同更新的重复数字。

## 检索方法

于2026-10-13使用中英文网络搜索，并打开能访问的官方公告、公共卫生调查、原始论文摘要和同期媒体。检索组合包含 infant formula / powdered formula / recall / Salmonella / Cronobacter / botulism / cereulide，以及奶粉、婴幼儿配方乳粉、召回、三聚氰胺、汞、碘、假冒、倍氨敏；与1996—2000、2001—2008、2010—2019、2020—2026年代及已识别品牌组合使用。

重点检索来源：FDA、CDC、WHO、ECDC、英国FSA、法国公共卫生署、加拿大CFIA、新西兰MPI、中国政府及监管/司法网页、香港CFS。来源目录逐项列出可访问程度。搜索摘要可核对的事实仅限摘要明确所述；无法访问全文的条目不填额外批次或最终判决。

来源优先次序是官方调查/抽检与司法文件、企业召回文件、原始调查论文、同期可靠媒体。企业公告和政府网站转载媒体分别标识，不用所在域名冒充独立监管结论。不同状态并非风险评级。

## 字段

|字段|含义|
|---|---|
|id|稳定事件/扩展记录标识|
|occurred|起病、发生或生产范围；未明则写明|
|announced|首次公开、召回与扩展公告时间|
|region|调查/销售市场，与生产国尽量分开说明|
|brands / product|当时商标、经销商和准确产品；假冒明确标注|
|category|问题类型，不是严重程度或品牌评分|
|evidence_status|检出、调查关联、可能污染、标签/法规缺陷、后续排除等|
|problem|有证据的中文摘要|
|affected_scope|批次、规格、生产或保质范围；举例不等于完整名单|
|action|下架、召回、调查等已公布行为|
|followup|后续调查、修正和已公布结论|
|source_ids|与sources.json关联的来源ID|
|notes|身份、归责、跨市场标准或证据限制|
|checked_on|本资料的核对日期，非公告日期|

## 覆盖缺口

这次检索没有完整枚举各国执法召回数据库和每年的地方抽检附件。1999—2000、2006—2007、2009、2014、2016、2018（除跨年疫情）、2021以前其他小规模召回以及多国非英语材料覆盖尤其不足。这些是检索缺口，不是“当年无事”的结论。

2008年条目附22家企业名单，但不是69批次完整编码表。2013年乳清事件下游品牌与批次尚未全部展开。2015年圣唐条目未获得逐批检验指标附件。2017年Lactalis跨境品牌清单及2026年欧洲毒素召回各国清单尚未穷尽。未取得具名信息的原始研究保留匿名。

病例是否由厂家成品导致、开封后污染来源、法院是否认定责任等仅在来源明确时写入。不纳入仅有匿名网帖、无明确产品时间和可追溯来源的传闻；不以排除传闻来暗示已完成所有投诉核实。

## 更新与去重

一次事件可有多个范围扩展记录。分析时按疫情/召回背景人工合并，不能直接把行数当作独立事故数。新的调查结论更新原条目并保留更正日志。未配置自动监控；此版本的检索截止日期固定，不承诺持续自动更新。
