# 婴幼儿奶粉事件资料库

整理1996年10月13日至2026年10月13日期间，中国及海外有公开来源的婴幼儿奶粉相关事件、召回和调查结果。只做事实摘要，不做品牌评分、推荐或当前安全性评价。

**版本：0.1.0｜核对日期：2026-10-13｜34条事件/扩展记录｜48个来源条目。**

这是一份跨30年检索窗口的初版历史资料集，**不是全网全部事件的穷尽清单**。不同地区和年代的公开记录可访问程度不一；某年、某品牌未列入，不表示没有事件。同一事件涉及多个厂家、多个国家和多次召回时，不把这些数字混作独立事故数量。

## 如何理解记录

“污染检出”“可能污染而预防性召回”“与病例有关的调查”“营养/标签或上市要求不符”“假冒销售”是不同事实。工厂环境阳性不能自动写成售出产品阳性；食用史、时间关联不能自动写成确定致病原因。召回结束、疫情结束和根因调查结束也分别记录。

每条保留发生/生产时间、公告时间、地区、产品、问题、证据状态、范围或批次、处置、后续结果和来源。能核对的批次直接列出，多产品长名单以原公告为准。未找到的信息明确留空或注明未核定，不从记忆填补。

本资料以粉状婴幼儿配方为主，特殊用途配方、成长配方和原料牵涉事件注明身份；固体饮料冒充奶粉、冒牌奶粉作为相关销售案件收录并明确区分。没有把液态普通牛奶、辅食罐头或成人乳粉事件混入主体。

## 检索范围的限制

初版来源主要覆盖中国大陆、香港、日本相关产品、美国、加拿大、法国、英国、新西兰和以色列。主要来源包括监管/公共卫生网站、司法案例、原始调查论文、企业召回公告及少量同期媒体。其他国家、早期档案、逐批抽检附件和较小规模地方召回仍可能遗漏。

1996年末—1997年初的首条疫情跨越窗口起点，确切起病日未查到，已在条目备注。未逐年收录的年份不提供零事件结论。2026年最新条目使用截至核对日可访问的调查更新。

本资料表达历史记录，不据此判断某品牌、企业或目前在售产品。来源原文及图片权利属于各自权利人，仓库仅保留链接与独立中文摘要。
